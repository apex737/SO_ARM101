# S01 — UART 패킷 수신 (설명용 예시)

- 목표 연결: G1 (패킷 수신)
- 현재 판정: 미검증
- 관련 기록: P01, C01, B01~B03, D01

## 사전 통과 기준
기존 요구사항이 없는 예시다. 실제 프로젝트에서는 입력 패킷·오류 조건·허용 유실을 먼저 정한다.

## D01 — 인터럽트에서 저장하고 태스크에서 조립
선택 이유: 인터럽트 처리 시간을 줄이는 설계 예시.
대안: 인터럽트에서 패킷 전체 처리. 실행 시간 증가 가능성을 고려해 제외한 가정.
대가: 버퍼·동기화 관리 필요. 실제 지연과 유실을 측정해 재검토한다.

## 검증 이력
실제 코드와 하드웨어를 실행하지 않았다. 화면 설명용이며 통과 증거가 아니다.
