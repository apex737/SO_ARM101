## 주문에 맞춰 부품을 담는 작업 키트 구성 로봇

1. PC에서 라파로 작업을 RESTAPI로 요청한다.
2. 라파는 FastAPI로 서버를 열어서 Request에 대해 Response 한다. ( UI는 Qt 를 최대한 활용할 것 )
3. JSON Response 를 받으면 그 명령을 파싱해서 피지컬 명령을 수행한다. 
4. 피지컬 명령은 그리퍼로 원하는 색깔의 물체를 집는 것이다. 
  5. 즉, 그리퍼는 모방학습을 통해, 색깔에 해당하는 물체를 집도록 학습된 상태로 가정함.
  6. 추론속도가 이 프로젝트의 핵심임. 그립에 실패했을때 이를 판단하고, 원상 복구 및 재시도할 수 있는 로직이 존재해야한다.
  7. 가능하다면 신뢰성도 프로젝트에 포함시키면 좋다. 즉, DB에 어떤 REQ를 받았는데, 실제 RESP를 넣었는데 동작이 성공했는지 여부도 확인할 수 있으면 좋다. 즉, 요청 검증, 작업 대기열, 장비 통신, 실패 처리, 로그, 운영 화면 모니터링 등 시스템의 신뢰성을 보장하는 기능들..
