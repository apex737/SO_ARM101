- 역할 분담(2026-11-11 확정, S02.md D09): ACT 범위 = 접근 이후 미세 보정 → 집기 → 바구니 → HOME. 실패 감지·복구는 별도 로직.

## 1. 테이블 짚기 — 22mm의 정체
```bash
s02 table
```
1. 리더암을 팔로워 자세와 비슷하게 맞추고 Enter.
2. 부리를 닫고 수직에 가깝게 세워 끝을 테이블에 **살짝** 댄다 → Enter. 가까이·중간·멀리·왼쪽·오른쪽 5곳 이상.
3. `q` Enter로 끝. `$RUN/table_touch.json`에 저장된다.

| 결과 (`summary`) | 판단 (사전 기준, 추정값) | 다음 |
|---|---|---|
| `z_range` ≤ 4mm 이고 `z_vs_distance` 절댓값 ≤ 2mm/100mm | 모델 원점과 테이블 사이의 **일정한 높이 차이**. 모든 높이를 같은 모델 좌표로 계산하므로 접근에는 영향 없음 | 22mm 문제는 닫는다 |
| 위 조건을 벗어남 | 위치에 따라 모델 높이가 변함 → 관절 0점 또는 팔 모델 오차 | 실험 3의 높이 차이(`height_offset_mm`)가 위치마다 다른지 함께 본다. 관절 0점은 오늘 바꾸지 않고 기록만 한다 |

- `model_minus_calib_table_z`: 테이블 짚기 높이와 화면 → 로봇 보정이 예상한 테이블 높이의 차이. 평균이 크면(±5mm 넘음) 보정점을 블록 윗면에 댈 때 높이가 달랐을 수 있다.

## 2. 손목 기준 만들기 — 사진 → mm 변환표
블록이 **두 부리 가운데 바로 아래**에 있을 때 손목 사진에서 어디·어떤 크기로 보이는지 기록한다. 그리퍼가 블록을 쥐면 닫히는 방향으로는 블록이 저절로 가운데에 온다는 성질을 쓴다.

```bash
s02 wristref --step
```
1. 리더암을 맞추고 Enter.
2. 리더암으로 블록을 **손가락 길이의 가운데**로 쥐고, 블록이 테이블에 닿은 채로 둔다. 그리퍼는 수직에 가깝게 → Enter.
3. 이후는 자동이다(`--step`이면 단계마다 Enter). 그리퍼 열기 → 수직으로 접근 높이까지 올라가기 → 기준 사진 → 그리퍼 좌표로 ±10mm 네 번 → 손목 +10° → 20mm 위 → HOME.
4. 블록 위치를 바꿔 **한 번 더** 실행한다. 두 번째 실행은 "이전 기준 대비" 차이를 출력한다.

| 출력 | 통과 (사전 기준, 추정값) | 벗어나면 |
|---|---|---|
| J 맞춤 잔차 | 3px 이하 | 팔 흔들림·검출 불안정. 조명·색 범위 확인 후 다시 |
| 각도 민감도 k | 절댓값 0.7~1.3 | 블록 각도 검출 불안정 |
| 카메라-블록 거리 | 20~300mm | 크기 측정 불안정 |
| 두 번째 실행의 "이전 기준 대비" | 중심 2mm·각도 2°·크기 3% 이내 | 블록을 쥔 위치가 달랐을 가능성. 한 번 더 해서 가까운 두 개 중 나중 것을 쓴다 |
| 집기 직전 벌림 추정 | 기록만 (닫힘 = 0mm·선형 가정) | 허용 오차 = (이 값 − 25) ÷ 2 로 다시 계산해 S02.md에 적는다 |

한계: 손가락 길이 방향으로는 블록이 저절로 가운데에 오지 않는다. 사람이 쥔 위치만큼(수 mm) 기준에 들어간다. 2회 비교로 크기를 확인한다.

## 3. 보정 없이 반복 접근 — 원래 치우침 재기
```bash
s02 approach --name near_0 --repeat 3 --step --corr none
s02 approach --name middle_0 --repeat 3 --step --corr none
s02 approach --name far_0 --repeat 3 --step --corr none
s02 report --prefix near middle far
```
- 각 위치에 블록을 각도 0°로 놓는다. 반복 사이에는 **블록을 건드리지 않고** Enter.
- 한 시행: HOME → 위 카메라 검출 → 계획 → 블록 위 40mm 접근 → 관절 진단 + 손목 사진 측정 → HOME. 사람이 리더암으로 맞추는 단계가 없다.
- 처음 한두 번은 `--step`으로 단계마다 확인하고, 이상이 없으면 `--step`을 빼도 된다.
- `--corr none`: 어제 리더암으로 모은 보정(`var/approach_corrections.json`)을 쓰지 않는다. 그 보정은 실제 관절값 기준이라 서보가 덜 가는 만큼이 빠져 있다. 비교가 필요하면 `--name middle_old --repeat 3`(기본 보정 사용)을 추가로 돌린다.

| 판단 | 사전 기준 (추정값) | 보는 곳 (`report`) |
|---|---|---|
| 같은 위치에서 반복된다 | 흩어짐 3mm·3°·높이 3mm 이하 | `repeat.*.spread_*` |
| 일정한 치우침이 있다 | 같은 위치 평균 오차가 흩어짐의 2배 이상 | `repeat.*.mean_mm` |
| 멀수록 바깥으로 밀린다 | 2mm/100mm 이상 | `radial_fit.b_mm_per_100mm` |
| 서보가 덜 간다 | 멈춤 시간 초과가 시행의 1/3 이상, 또는 어깨·팔꿈치 (목표 − 실제) 평균 1° 이상 | `settle_timeout`, `target_minus_read_deg_mean` |
| 손목 카메라에 목표가 보인다 | 모든 시행 | `wrist_visible` |

| 결과 | 다음 |
|---|---|
| 반복되고 치우침이 작음 (모든 위치 평균 오차 5mm 이하) | 4를 건너뛰고 5로 (`--corr none`) |
| 반복되고 일정한 치우침이 있음 | 4로 |
| 같은 위치에서도 흩어짐이 큼 | 보정으로 덮지 않는다. 서보 진단 값과 사진(`var/exp_s02/frames/`)을 남기고 멈춘다. 원인 후보: 카메라 장대 흔들림, 서보 유격, 검출 흔들림 |
| 손목 사진에서 못 찾는 시행이 있음 | 사진을 보고 가림·시야 밖·색 문제를 구분한다. 시야 밖이면 그 위치는 작업 범위에서 뺀다 |

## 4. 보정 기록 자동 수집 — 3에서 일정한 치우침이 보일 때만
```bash
cp var/approach_corrections_wrist.json "$RUN/wrist_corr_before.json" 2>/dev/null; rm -f var/approach_corrections_wrist.json
for i in 01 02 03 04 05 06 07 08 09 10; do
    read -p "블록을 수집 위치 $i 에 놓고 Enter (각도는 0°와 30°를 섞기) "
    s02 approach --name collect$i --corr none --collect || break
done
python -c 'from kitbot_exec.correction import Correction, load_samples; from kitbot_exec.exp_s02 import WRIST_CORR; print(Correction(load_samples(WRIST_CORR)).summary())'
```
- 작업 영역 전체에 고르게 10곳. **5의 평가 위치와 겹치지 않게** 한다.
- 기록은 `var/approach_corrections_wrist.json`에 쌓인다. 6건 이상이면 위치별 1차식이 된다.
- 기록 기준은 **명령값**이다: "이 위치를 명령했더니 블록이 사진상 e만큼 옆에 있었다 → 다음엔 명령 + e". 서보가 덜 가는 양까지 이 보정에 들어간다.
- **두 번 보상 금지:** 나중에 실행 단계 서보 보상(BiasFixPlan의 코드 변경 1)을 넣으면, 이 보정은 버리고 다시 모아야 한다. 오늘은 서보 보상 코드를 넣지 않는다.
- 실제 블록 위치(읽은 관절값 기준)도 `block_true_read_xy`로 함께 남긴다.

## 5. 별도 위치 평가 — 9곳 × 각도 2종
작업 영역에 3×3 위치를 정한다(4의 수집 위치와 다른 곳). 테이프로 표시해 두면 블록을 다시 놓기 쉽다(길이를 잴 필요는 없다).

```bash
CORR=var/approach_corrections_wrist.json     # 4를 건너뛰었으면 CORR=none
for g in 01 02 03 04 05 06 07 08 09; do
  for a in 0 30; do
    read -p "블록을 grid$g 위치에 ${a}°로 놓고 Enter "
    s02 approach --name grid${g}_${a} --corr "$CORR" || break 2
  done
done
s02 report --prefix grid
```
- 계획 실패·블록 미검출·손목 미검출도 분모에 들어간다(`pass`의 분모 = 전체 시행).
- 평가 중에 보정을 다시 맞추면 더 이상 별도 평가가 아니다. 그때는 새 평가 위치를 정한다.

**판정 (사전 기준)**
| 항목 | 기준 | 보는 곳 |
|---|---|---|
| S02 참고 판정 | 오차 10mm 이하 + 각도 10° 이하가 시행의 90% 이상 (`pass_rate` ≥ 0.9) | `pass`, `pass_rate` |
| ACT 인계 조건 ① 시야 | 손목 카메라에 목표가 보임: 18/18 | `wrist_visible` |
| ACT 인계 조건 ② 높이 | 접근 높이 차이(최대 − 최소) 10mm 이하 (추정값) | `height_offset_mm` |
| ACT 인계 조건 ③ 남은 오차 범위 | 기록만: 최대 오차·각도 → 시연 때 접근 목표를 일부러 흔들 범위 = 이 값 + 5mm·5° (추정값) | `err_mm_abs.max`, `err_yaw_deg.maxabs` |
| 서보 상태 | 멈춤 시간 초과 비율 기록 | `settle_timeout` |

- 10mm 기준은 접근 품질의 참고 숫자다. ACT가 남은 오차를 처리할 수 있다는 증거는 아니다. 그건 ACT 평가에서 확인한다.
- S02 판정: 참고 판정 통과 + 인계 조건 ①② 충족 → "통과". 참고 판정은 못 넘었지만 ①② 충족 → 남은 오차를 원인별로 기록하고 "탐색 완료"로 닫은 뒤 ACT 시연으로 넘어간다(ACT가 다룰 범위로 기록). ①이나 ②를 못 넘으면 접근 단계에서 먼저 해결한다.
