## 확정 (사용자 결정)
- 배치 안 2: 팔·카메라는 GPU 노트북(RTX 4050 6GB)에 USB로 연결한다. Pi 5는 주문·대기열·DB와 "red 하나 집어" 같은 명령·결과 판정을 맡는다. Pi↔노트북은 이더넷·Wi-Fi 둘 다 가능.
  - 근거: 영상 → 추론 → 동작 반복이 한 컴퓨터 안에서 끝나 네트워크 지연이 끼지 않는다. LeRobot은 PC 환경에서 가장 잘 동작한다. Pi용 RealSense 드라이버를 빌드하지 않아도 된다.
- 핵심은 객체 인식 + 그리퍼 학습 전략이다. 신뢰성 기능(pjt.md 7번)은 필요할 때 옵션으로 붙인다(S08).
- 작업대: 정육면체 블록, 최대 8개(어려우면 조정 가능).
- G3 완료 조건: 학습에 쓰지 않은 위치에서 집기 성공률 80% 이상. 그만큼 중요한 것: 실패한 경우 실패를 인식하고 홈으로 돌아와 재시도할 수 있어야 한다.
- 학습은 6GB 노트북에서 한다. 부족하면 클라우드를 나중에 검토한다.
- 카메라: RealSense 1대 + USB 웹캠 2대(손목용 1, 작업대 전체·키트 박스용 1).

## 지난 ACT 실습 진단 (사용자: "제한된 반복 작업만 수행")
- ACT는 시연 궤적을 거의 외운다. 물체 위치가 좁게 고정된 데이터에서는 그 위치에서만 동작한다.
- ACT에는 "빨강을 집어라" 같은 지시를 받는 입력이 없다.
- 복구 장면이 데이터에 없으면 놓친 뒤 할 줄 아는 게 없다.
- 결론: 정책 하나에 인식·판단·동작·복구를 다 맡긴 구조가 문제. 학습이 꼭 필요한 부분만 학습시킨다.

## 제안: 집기 구조 (2단 접근 + 4분할) — 사용자 확인 대기
사용자가 "인식한 위치까지 가서 집을 수 있는 각도로 그리퍼를 편다"를 1단계로 정리했고, AI는 이 방식이 원래 제안(다가가기까지 정책이 학습)보다 낫다고 판단했다.
1. 인식 + 거친 접근(계산): RealSense로 블록 위치·회전각 → 역기구학으로 블록 위 몇 cm 지점, 블록 각도에 맞춰 그리퍼 열기.
2. 정밀 집기(학습): 손목 카메라로 내려가며 위치를 맞추고, 닫고, 들어 올린다. 1단계의 위치 오차는 여기서 정책이 메운다.
3. 놓기(고정 동작 재생 + 칸 위치만 더하기).
4. 확인: 카메라 + 서보 신호(끝까지 닫힘 = 빈손, 부하 유지 = 잡음).
- 이유: 정책은 어디서든 "블록 바로 위에서 집기"라는 비슷한 장면만 배우면 된다 → 본 적 없는 위치에 유리하고, 데이터가 덜 든다.
- 대가: 카메라-로봇 좌표 보정과 SO-101 역기구학이 필요하다(S04).
- 2와 3을 나눈 이유
  - 들어 올린 직후에 확인 → 빈손이면 그 자리에서 홈 복귀·재시도. 묶으면 빈손으로 박스까지 다녀온 뒤에야 안다.
  - 박스 위치가 고정이라 재생 동작이 거의 매번 같게 동작하고, 데이터도 필요 없다.
  - 녹화가 짧을수록 모방학습이 쉽고, 실패 원인이 어느 단계인지 보인다.
- "똑똑한 재시도"의 실체: 실패 → 홈 → 목표를 다시 인식(밀렸을 수 있음) → 새 위치로 다시 접근.
- 비교 후보(실험으로 결정): A 색별 ACT(기준선) / B ACT + 목표 위치 입력 / C 문장 지시형 모델(SmolVLA 등, 6GB 학습 빠듯해 보류) / D 학습 없이 인식 + 역기구학만.

## 제안: 모델 — ACT 먼저, Diffusion은 S06에서 비교
- Diffusion 장점: 정답 동작이 여러 개인 상황 표현, 부드러운 동작.
- Diffusion 단점: 계산을 여러 번 반복해 추론이 느리다(4050에서 수십~수백 ms, 추정). 학습도 오래 걸린다.
- 2단 접근에서는 인식이 목표를 정해 주므로 "여러 정답" 상황이 줄어든다. 추론 속도가 핵심이라 ACT 우선. 같은 데이터로 성공률·추론 지연을 비교한다.

## 제안: 카메라 역할
| 카메라 | 위치 | 역할 |
|---|---|---|
| RealSense | 작업대 위 고정 | 블록 3D 위치·회전각, 집은 뒤 자리가 비었는지 깊이로 판정 |
| USB 웹캠 1 | 손목 | 정밀 집기 정책 입력 |
| USB 웹캠 2 | 작업대 전체·키트 박스 | 놓였는지 확인, 운영 화면, 필요하면 정책 입력 |
- RealSense를 웹캠으로 대체하지 않는다. 깊이가 없으면 그림자와 블록 구분, "블록이 들렸는지" 판정이 어렵다.
- RealSense를 손목에 다는 것은 근거리용 D405가 아니면 비추천(최소 측정 거리·무게).
- 자동 노출·화이트밸런스를 끄고 고정한다(HSV가 흔들리는 가장 흔한 원인).
- 깊이를 정책 입력에 바로 넣는 것은 처음엔 하지 않는다(소량 데이터에서 이득이 작을 것으로 추정). 깊이는 인식·판정에 쓴다.

## 제안: 8색
- RealSense 컬러 센서는 일반 웹캠 수준이고, 깊이는 색 구분에 도움이 안 된다. 깊이로 블록을 오려 낸 뒤 블록마다 색을 판별한다.
- 섞이기 쉬운 색: 빨강·주황·분홍·보라, 노랑·주황, 파랑·하늘색. S02에서 실제 블록으로 혼동 정도를 측정한다.
- 정책은 목표 위치만 받으므로 색 수와 정책 난이도는 무관하다.
- 실제 어려움은 블록 간격(손가락이 옆 블록에 부딪힘). 학습은 3~4개를 띄엄띄엄 놓고 시작하고, 평가에서 8개로 올린다.

## 제안: 추론 속도의 정의
- 추론 지연(관찰 → 동작 묶음 계산), 제어 주기(서보 명령 간격, 보통 30Hz), 작업 시간(블록 하나를 집어 담는 시간)을 구분해 측정한다.
- 핵심은 로봇이 추론을 기다리며 멈추지 않는 것. 필요하면 LeRobot 비동기 추론을 쓴다(버전별 기능은 설치 시 확인).

## 추가 논의: ACT가 맡는 범위와 키트 칸 (2026-11-09)
- 사용자 이해 확인: "입을 벌린 상태에서 집어서 키트에 넣기까지 ACT"로 정리함 → AI 정정: ACT는 **집고 들어 올리기까지만**. 키트에 넣기는 고정 동작이다(2·3 분리 이유는 위 절).
- 목표 위치·키트 칸은 중요하다. 다만 학습이 아니라 계산·설계로 푸는 문제다.
  - 블록 위치·회전각: 1단계(인식 + 역기구학 접근)의 입력. 허용 오차 ≈ (그리퍼 벌림 폭 − 블록 폭) / 2. 남는 오차는 ACT가 손목 카메라로 메운다. 실제 값은 그리퍼·블록 측정 후 계산.
  - ACT에 블록 좌표를 추가 입력으로 줄지는 나중 실험(손목 카메라만으로 충분할 수 있음).
  - 키트 칸: 키트 박스를 격자로 나누고(예: 8개면 2×4, 박스·블록 크기 측정 후 결정) 작업마다 칸을 배정한다. 칸마다 놓기 자세를 미리 기록해 두고 재생한다(→ 11-10에 키트 표식으로 칸 좌표를 계산해 놓는 방식으로 바뀜). 놓은 뒤 웹캠 2로 "그 칸에 그 색이 있는지" 확인한다. 칸 배정은 tasks 표에 slot 열로 추가할 예정.
- 순서 의존성: ACT 시연 데이터는 1단계가 실제로 만들어 내는 시작 자세(블록 위, 그리퍼 벌림)에서 녹화해야 한다. 사람이 아무 자세에서 시작해 녹화하면 실행할 때의 시작 상태와 달라진다. 그래서 인식 → 보정·접근 → ACT 데이터 수집 순서로 간다.

## 추가 논의: 하이브리드 vs 전체 학습 (2026-11-09) — 실험으로 결정
- 사용자 우려: 학습은 블랙박스에 가까운데, 접근(다가가서 그리퍼 벌리기)만 통제하는 전략이 100% 학습보다 나은지 확신하지 못함.
- AI 답: 확신할 수 없다. 실험으로 정한다. 하이브리드에 먼저 거는 근거(제안):
  - 학습에 어려운 것(처음 보는 위치로 다가가기)과 계산에 어려운 것(접촉 순간 정밀 정렬)이 다르다. 쉬운 건 계산, 어려운 건 학습.
  - 블랙박스 축소: 전체 성공률 = P(접근 정확) × P(집기 | 접근 정확). 앞쪽은 mm 단위로 측정 가능.
  - 데이터가 적은 조건(6GB, 사람 시연)에서 학습 범위를 좁히면 유리(추정).
  - 재시도 때 다시 인식한 새 위치로 접근.
- 하이브리드가 질 수 있는 경우: SO-101 서보 유격·보정 오차가 그리퍼 허용 오차보다 큼(수 mm~1cm, 추정), 보정·역기구학 구현 비용, 촘촘한 배치에서 경로 충돌.
- 비교 실험(같은 시험 위치·같은 기준: 첫 시도 성공률, 실패 유형)
  | 방식 | 내용 | 비용 |
  |---|---|---|
  | 0 학습 없음 | 인식 + 역기구학 접근 + 고정 동작으로 내려가 닫기 | 보정 후 바로. 데이터 불필요 |
  | 1 하이브리드 | 접근은 계산, 집기는 ACT | 시연 데이터 |
  | 2 전체 학습 | 홈부터 ACT(목표 위치 입력 포함) | 작업 공간 전체 시연 데이터 |
- 순서: 0번 먼저. 0번에서 접근 오차(mm)를 측정한다.
- 갈림길 기준: 접근 오차 ≤ 그리퍼 허용 오차 → 하이브리드. 허용 오차보다 훨씬 크고 보정으로 안 줄면 → 전체 학습 쪽으로 기운다. (허용 오차 ≈ (그리퍼 최대 벌림 폭 − 블록 한 변) / 2, 측정 후 계산)
- 데이터 재사용: 시연을 홈부터 끝까지 녹화 → 2번 학습에 그대로, 같은 녹화에서 "블록 위 몇 cm 안에 들어온 뒤" 구간을 잘라 1번 학습에 사용. 주의: 잘라 낸 구간의 시작 자세는 사람이 만든 것이라 역기구학 접근 자세와 다를 수 있음 → 실험에서 함께 확인.
- 다음 현장 작업 목록은 어느 방식이든 그대로 필요하다.
